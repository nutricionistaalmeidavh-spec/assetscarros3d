# AssetsCarros3D — biblioteca ArtiSys

Espelho de arquivos 3D de https://github.com/pedrosoandre/carros.
Este repositório contém o catálogo, seus arquivos GLB e os créditos
obrigatórios dos autores em CREDITS.md.

O commit exato da origem importada está em UPSTREAM_COMMIT.txt.
Leia README_ORIGEM.md para documentação e opções de uso.
A licença MIT cobre código e metadados; modelos 3D possuem licenças
individuais CC BY/CC BY-SA, conforme CREDITS.md e cars.json.
Os arquivos são mantidos localmente; nenhuma API paga é necessária.
